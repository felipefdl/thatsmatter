# ThatsMatter

Expose Home Assistant devices to Matter controllers (Alexa, Google Home, SmartThings, Apple Home, and others) as a local Matter bridge.

Nothing leaves Home Assistant until you add it to the export catalog. You control the name, type, and which entities each controller sees.

## Status

Design / early development. Not ready to install.
